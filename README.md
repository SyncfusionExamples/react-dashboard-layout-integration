# Presale Dashboard Sample

A React and TypeScript dashboard sample featuring Syncfusion Dashboard Layout, AG Grid Community, and Plotly charts. The dashboard includes sample sales data and responsive, draggable, resizable panels.

## Run the application

### Requirements

- Node.js and npm

### Setup

Open a terminal in the project folder and install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL printed in the terminal, usually [http://localhost:5173](http://localhost:5173).

To stop the development server, press `Ctrl+C` in the terminal.

## Available commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
| `npx tsc --noEmit` | Check TypeScript types |
